### 1. KEFRI Nursery Cost-Benefit Analysis 
* **Focus Area**: Dryland Agroforestry Economics
* **Overview**: Conducted an empirical cost-benefit analysis evaluating tree seedling production efficiencies at KEFRI Kitui. The research tracked financial inputs, input-output variables, and seedling propagation lifecycles for critical dryland species including *Melia volkensii*, *Punica granatum*, and *Acacia tortilis*.
